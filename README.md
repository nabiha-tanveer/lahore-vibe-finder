# 🌆 Lahore Vibe Finder

A fully static, mood-based web app to discover cafés and study spots across Lahore — pick a vibe, search, sort, rate, favorite, and even book a visit. Built entirely with **HTML, CSS, and vanilla JavaScript** — no backend, no frameworks, no database.

![Made with HTML CSS JS](https://img.shields.io/badge/Made%20with-HTML%20%7C%20CSS%20%7C%20JS-orange)
🔗 **Live Demo:** [https://lahore-vibe-finder.vercel.app/](https://lahore-vibe-finder.vercel.app/)

---

## ✨ Features

- 🎯 **Mood-based filtering** — Chill, Study, Aesthetic, Budget
- 🔍 **Live search** — instantly filter spots by name
- ↕️ **Sort options** — by Name, Rating, or Popularity
- ⭐ **Interactive star ratings** — click to rate any spot, live average updates
- ❤️ **Favorites system** — save spots with a heart click, persisted via `localStorage`
- 🎲 **Surprise Me** — get a random spot recommendation
- 📅 **Book a Visit** — pick a name, date, and time to simulate booking a spot
- 💰 **Price tags** — quick price indicator per spot
- 🔔 **Toast notifications** — instant feedback for every action
- 🌙 **Dark / Light mode toggle**
- 💬 **Rotating testimonials slider**
- 📧 **Newsletter form** with real-time email validation
- ⌨️ **Typewriter animated heading**

All interactivity is powered by **vanilla JavaScript** — no libraries, no frameworks.

---

## 🛠️ Tech Stack

| Layer      | Technology              |
|------------|--------------------------|
| Structure  | HTML5                   |
| Styling    | CSS3 (custom properties, animations, responsive grid) |
| Behavior   | Vanilla JavaScript (ES6) |
| Storage    | Browser `localStorage`  |

No backend, no server-side code, no database — fully static as required.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/nabiha-tanveer/lahore-vibe-finder.git
   ```
2. Open `index.html` directly in your browser — or use a tool like VS Code's **Live Server** extension for the best experience.

No installation, build step, or dependencies required.
